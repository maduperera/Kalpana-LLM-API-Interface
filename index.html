💬 POST /v1/chat/completions

Chat

Send a message and get a response powered by RIF context retrieval. Optionally attach a Knowledge Pack ID for document-aware answers.

Python 
import requests

BASE_URL = "https://madurox-kalpana-api-cpu.hf.space"

# Simple chat request
response = requests.post(
    f"{BASE_URL}/v1/chat/completions",
    json={
        "model": "qwen2.5-72b",
        "messages": [{"role": "user", "content": "Hello!"}],
        "max_tokens": 512,
        "temperature": 0.7
    }
)
print(response.json()["choices"][0]["message"]["content"])
Python — With Knowledge Pack 
# Chat with a Knowledge Pack for document-aware answers
response = requests.post(
    f"{BASE_URL}/v1/chat/completions",
    json={
        "model": "qwen2.5-72b",
        "messages": [{"role": "user", "content": "Summarize the key points."}],
        "active_pack_id": "kp_a1b2c3d4",
        "max_tokens": 512,
        "temperature": 0.7
    }
)
print("Answer:", response.json()["choices"][0]["message"]["content"])
print("Token Savings:", response.json()["cost_comparison"]["savings"])

📚 POST /v1/knowledge_packs/compile

Knowledge Packs

Compile raw text into a RIF Knowledge Pack. Returns a pack_id for use in chat.

Python 
response = requests.post(
    f"{BASE_URL}/v1/knowledge_packs/compile",
    json={
        "text": "Your long document text here...",
        "bandwidth": 2048
    }
)
pack_id = response.json()["pack_id"]
print("Pack ID:", pack_id)

📄 POST /v1/knowledge_packs/compile_file

Knowledge Packs

Upload and compile a PDF or TXT file into a Knowledge Pack.

Python 
files = {"file": ("document.pdf", open("document.pdf", "rb"), "application/pdf")}
response = requests.post(
    f"{BASE_URL}/v1/knowledge_packs/compile_file",
    files=files,
    data={"bandwidth": 2048}
)
print("Pack ID:", response.json()["pack_id"])

🔌 POST /v1/providers/register

Providers

Register your own LLM API key (Groq, OpenAI, Together, Cerebras, OpenRouter, or custom).

Python 
response = requests.post(
    f"{BASE_URL}/v1/providers/register",
    json={
        "provider": "groq",
        "api_key": "gsk_your_groq_key_here",
        "model": "llama-3.1-8b-instant"
    }
)
print(response.json())
